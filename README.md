# Browser Beat Machine

A browser-based drum machine / step sequencer built with JavaScript, HTML and CSS.

## Features

- 16-step sequencer
- BPM control
- Keyboard triggers
- Custom sample switching
- Download loop as WAV
- Default editable groove

## Development Notes

This project was built using modern AI-assisted workflows alongside hands-on development. I directed feature design, integrated custom audio samples, tested functionality, debugged issues, and refined the user experience throughout development.
